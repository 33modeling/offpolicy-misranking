## 1. 공식 일정

공식 날짜와 아래 내부 준비 목표를 구분한다. 공식 일정은 2026-09-28에
[ICLR Dates](https://iclr.cc/Conferences/2027/Dates)와
[Call for Papers](https://iclr.cc/Conferences/2027/CallForPapers)를 확인했다.

| 날짜 | 공식 단계 | 우리 작업 |
| --- | --- | --- |
| 2026-09-25 | 논문 제출 마감 | 제출 V6 보존; 이후 작업은 V7에서 준비 |
| 2026-10-01–10-21 | 리뷰 작성 기간 | 전체 계획 실험 수행·비용 수집과 V7 반영 병행 |
| **2026-11-05** | **리뷰 공개, 저자–리뷰어 토론 시작** | 실제 review 원문 보관, 질문별 근거 연결, 응답 작성 |
| **2026-11-18** | **저자–리뷰어 토론 종료** | 응답 및 수정 PDF 반영 완료 |
| 2026-11-19–12-16 | 리뷰어–AC 비공개 토론 및 결정 과정 | 제출한 답변·결과 snapshot 보존 |
| **2026-12-16** | **최종 결정** | 결정과 meta-review 확인, 후속 원고 계획 |

리뷰 작성 기간은 [공식 Reviewer Guidelines](https://iclr.cc/Conferences/2027/ReviewerGuidelines)의
일정을 따른다. 현재 우려 목록은 저자가 전달한 비판·자체 점검이며, 실제 공식 review를
열람했다고 기록하지 않는다.

CFP의 시간대 기준은 AoE(UTC−12)다. **날짜만 기재된 리뷰 공개·토론 종료를
임의로 한국시간 00:00 또는 23:59 마감으로 확정하지 않는다.** 정확한 시각은
OpenReview 해당 submission 안내에서 다시 확인한다. 아래 내부 마감은 KST다.

공식 [Author Guidelines](https://iclr.cc/Conferences/2027/AuthorGuidelines)에 따르면
리뷰 공개 전에는 제출 파일을 수정할 수 없고, 공개 토론 동안 수정본을 제출할 수 있다.
현재 안내의 rebuttal 본문 한도는 **10쪽**이다. 변경 내용은 리뷰어가 찾을 수 있게
정리하며 원래 논문과 크게 달라지는 변경은 검토되지 않을 수 있다.
V7 로컬 작성·실험 준비와 OpenReview 제출 완료는 별개로 기록한다.

첫 완료 작업의 wall-time과 실제 가용 노드 수를 확인하면 각 목표일을 갱신한다.
지연이 예상되면 자원 재배정·실패 복구·미구현 작업의 병목을 먼저 해결한다.
**P3도 완료 대상이며, 자원이 부족하다는 이유로 계획에서 자동 제외하지 않는다.**
그래도 11월 4일을 넘길 전망이면 미완료 범위와 필요한 추가 자원을 명시해 목표 조정을
결정한다. 현재는 실제 장비 수가 미확인이라 완료 가능성을 확정하지 않는다.
마감에 맞추려고 seed를 골라 빼거나, 일부 성공 사례만 최종 평균으로 보고하지 않는다.

V7 준비 완료는 PDF만 생성했다는 뜻이 아니다. E01–E10의 결과·비용 검증,
본문/부록의 반영, 표·그림 원자료 연결, 제출 V6와의 차이 기록이 모두 필요하다.
예전 잘못된 비용 숫자도 올바른 원자료 확인 없이 임의 대체하지 않는다.

## 4. 실제 리뷰 공개 후 기록 형식
